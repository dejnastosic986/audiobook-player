# Welcome — read this before posting

This is the community space for AudioVault's **server side** — `Install.sh`,
the setup guide, and AudioVault Manager. The Android app's source isn't in
this repo, so please don't post Android-app-specific bug reports here (use
the Play Store's feedback channel for that instead).

## Before you post

1. **Search first.** Use the search bar at the top of Discussions — someone
   may have already hit the same error.
2. **Q&A** category → setup problems, "why doesn't this work," general
   questions.
3. **Show and tell** → your server setup, your library, anything you built
   on top of this.
4. **Ideas** → feature requests or suggestions for the scripts/guide/Manager.
5. **Announcements** → I'll post here when `Install.sh` or the scripts
   change in a way you should know about (read-only for everyone else).

## What makes a question easy to answer fast

- **The exact error text**, not "it doesn't work." Copy-paste beats a
  screenshot when possible — it's searchable for the next person.
- Whether you're using **`Install.sh` directly** or **AudioVault Manager**.
- If you're using AudioVault Manager: open the **Diagnostics** tab, click
  **Run checks**, and paste what's OUTDATED or MISSING.
- Roughly when you last ran `Install.sh` / updated — a lot of issues turn
  out to be an older sudoers rule or script that just needs a re-run.

## A quick reminder on what this project is (and isn't)

Straight from the guide's philosophy section: no logins, no public catalog,
no discoverability — this is a personal/family tool, not a public sharing
platform. Questions about running it that way are outside what this project
is built for.

Glad you're here — ask away.
